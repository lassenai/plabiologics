사용 순서

샘플을 선택하거나 PNG·JPG·WebP 이미지를 열어주세요. 보기 방식과 판정 기준을 조절한 뒤 메모와 결과를 저장할 수 있습니다. 업로드 이미지와 메모는 외부로 전송되지 않습니다.

분석 방법

공개 샘플은 경량 머신러닝 모델의 저장된 예측입니다. 새로 연 이미지는 밝기 변화가 작은 부분을 찾는 텍스처 기반 영상처리로 분석하며, 학습 모델 추론과 다릅니다. 원본 비율을 유지해 긴 변을 256픽셀로 축소합니다.

입체 화면은 2D 밝기를 높이로 표현한 2.5D 표면입니다. 세포 두께·조직 깊이를 복원하지 않습니다. 빈 영역 비율은 생존율·치료 효능이 아닙니다. 모델 점수는 보정된 확률이 아닙니다.

공개 데이터

BBBC019v2 / SN15 · DA3 세포 DIC 영상. 태반유래 MSC 영상이 아닙니다. 이미지·정답 마스크를 축소하고 빈 영역 마스크를 계산했습니다.

평가 11장 / 파일명 그룹 6개 · 고정 기준 0.20에서 평균 Dice 0.804, 평균 면적 오차 1.38%p. 각 이미지의 판정 기준을 바꾸면 현재 지표도 바뀝니다. 회사 데이터 검증과 구분해야 합니다.
